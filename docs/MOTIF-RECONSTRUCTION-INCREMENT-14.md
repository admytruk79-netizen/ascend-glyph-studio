# A permitted embroidery reference with separate macro and micro studies

Retained Met object 239343, Blackwork Embroidery, ca. 1590, accession 2013.598: linen embroidered with silk and gilded silver metal-wrapped threads. The current object response declares isPublicDomain=true, and the original Open Access image is retained with its SHA-256. The culture field is empty, so attribution remains unassigned. This is an embroidery reference, not another woven Ottoman textile or a Ukrainian source.

Used the existing observed-annotation adapter, containment/clearance checks, reconstruction, construction profile and SVG renderer to reconstruct one large serrated leaf-like envelope and its approximate diagonal interior vein. The draft has two elements, 79 landmarks and one spatial nest; it makes no inferred stitch attachment. Rendered the source overlay and refined the interior line after visual comparison. Geometry remains approximate: zero coordinate error measures preservation of the supplied landmarks, not source-image tracing accuracy.

A separate 175 by 143 pixel patch inside the leaf studies its small rosette-like repeat texture. Dark pixels are selected explicitly by R<130, G<125 and B<115, without smoothing. The existing mask-contour adapter and independent contour rasterizer preserve this mask with zero pixel errors: 9,319 foreground pixels, 39 connected components, 64 loops and 25 holes. These counts describe thresholded image pixels, not individual flowers, stitches or fabric holes. Texture, shading and damage can affect the mask. The micro graph is separate from the macro leaf; it is not clipped, scaled and placed as a completed interior fill or learned repeat grammar.
