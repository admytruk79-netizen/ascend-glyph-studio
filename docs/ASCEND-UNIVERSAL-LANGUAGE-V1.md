# ASCEND Universal Pattern Language v1
This is a synthesis, not a style collage.

Design laws:
- counted geometry gives precision;
- balanced asymmetry prevents mechanical wallpaper;
- interlocking/crossing creates relational syntax;
- nested micro-pattern creates information depth;
- branching/blooming carries organic hierarchy;
- layered repeat permits textile-scale expansion;
- interruption and drift encode grammatical change;
- negative space is an active carrier;
- the same semantic skeleton survives narrow bands and large fields;
- no historical geometry is copied.

A sentence is expressed by the whole field. Individual primitives are not substitute letters. Meaning is carried by primitive choice + adjacency + transformation + density + interruption + macro-structure.
