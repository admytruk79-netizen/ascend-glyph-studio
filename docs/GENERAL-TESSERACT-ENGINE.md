# General Tesseract Engine

The semantic graph and multiscale floral system are engine capabilities, not diary-only features.

Supported substrate profiles now include diary, garment, stationery, emblem, packaging and digital. Each profile supplies physical dimensions, minimum feature size, density preference and suitable projections. It does not redefine the underlying ASCEND meaning graph.

This establishes the architecture:
meaning graph → original morphology → multiscale field → projection → substrate constraints → manufacturing validator.

A single seed can therefore generate related but differently projected work across a diary, shirt band, stationery border, emblem, package or digital animation.

Current SVG output is a deterministic multiscale field. Next work must apply each substrate's real dimensions/minimum-feature/density constraints to geometry and connect physical substrates to the manufacturing validator before any output is called production-ready.
