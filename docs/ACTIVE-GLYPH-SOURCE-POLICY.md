# Active Source-of-Truth Policy

The active Tesseract exploration pipeline no longer selects geometry from the legacy atlas.

Current source chain:
research principles → ASCEND semantic graph → new original `asc-new-*` SVG vocabulary → pattern archetypes → complex generations → multiscale fields → substrate projections.

Every active pattern case records provenance:
- `kind: original-synthesis`
- `legacyAtlasRequired: false`
- `copiedHistoricalMotif: false`

The historical/legacy atlas remains preserved for archival comparison only. It is not an input to active geometry generation.

The deterministic deep exploration test covers 6,144 candidates (12 archetypes × 64 variants × 8 generations) and requires more than 1,000 unique complexity signatures while retaining original-source provenance.
