# Pattern training corpus v1

This is deterministic design-space training, not foundation-model training.

Tesseract now explores 12 controlled pattern archetypes with 8 seeded variants each (96 cases): lineage axis, journey band, nested rhombic, alternating register, mirrored branch, stepped ascent, guarded field, interlock lattice, continuous meander, radial center, quartered field and interrupted rhythm.

Every case retains immutable atlas source references and carries evaluation objectives for traceability, negative space, rhythm, complexity and manufacturability. The current canonical gate means training uses only water-02 and water-03 until additional authored atlas fragments pass geometry verification.

The archetype names are ASCEND synthesis vocabulary. They are not claims that historical Ukrainian or Belarusian makers used these names or assigned these meanings.

Next: expand canonical atlas verification, add evidence-backed regional morphology profiles, render each training case into diary bands/borders/dividers, and rank actual geometry rather than manifests alone.
