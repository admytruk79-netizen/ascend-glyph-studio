# Deep pattern exploration v2

The 96-case corpus was a deterministic smoke test. The engine now supports multi-generation exploration.

Reference deep run:
- 12 base archetypes
- 64 variants per archetype
- 8 generations
- **6,144 raw deterministic candidates**
- 3–8 compositional registers per candidate
- 2–6 transitions
- 2–8 controlled mutations
- duplicate complexity signatures removable before ranking

Registers: root, threshold, path, guardian, crown, edge, corner, field.

Transitions include step shifts, mirror flips, density gradients, alternating gaps, nested returns, quarter turns, axis breaks and cadence changes.

Mutations include scale/mirror alternation, quarter rotation, phase offsets, nested insets, interlocks, interrupt/resume rhythm, edge reflection, corner folding, center accents and controlled sparse/dense contrast.

This is still a constrained design search, not a claim of ML model retraining. Every case remains deterministic and provenance-carrying. Increasing candidate count does not relax canonical atlas or manufacturing gates.

Next evaluation stage should render and geometrically score the unique candidates, cluster near-duplicates, then recursively mutate only the strongest families.
