# Tesseract Ornamental Pattern Maker — visual acceptance contract

## Purpose
Generate sophisticated, coherent ASCEND ornaments from canonical glyphs and source-grounded motif grammars, not literal graph edges, arbitrary lines, or decorative noise.

## Required pipeline
1. Ingest rights-cleared image references and preserve attribution, tradition, material and evidence tier.
2. Segment actual visual motifs (silhouettes, cavities, repeat cells, spatial relations). Never treat metadata centroids as extracted motifs.
3. Reconstruct held-out reference layouts from extracted motifs; report measurable geometry, hierarchy and repeat closure.
4. Build multi-scale composition: dominant motif, supporting satellites, recursively nested cavity motifs, connectors that are themselves valid motif parts, and restrained fillers.
5. Support continuous rotation, reflection, variable scale, interlock, radial and translational repetition. No fixed low motif-instance ceiling.
6. Enforce repeat-cell continuity, symmetry intent, hierarchy, intentional negative space and embroidery stroke/spacing constraints.
7. Render actual motif silhouettes with controlled palette and material-specific production constraints.
8. Evaluate raster previews and source reconstructions; fail closed. Return no candidates when none pass.
9. Present side-by-side reference reconstruction and new ASCEND variation for human visual approval before production.
10. Export dimensioned vector geometry and a provenance/rights manifest; physical sew-out approval remains mandatory.

## Hard visual rejection criteria
- Visible semantic-graph edges or disconnected scribbles
- Unintended intersections, arbitrary overlaps, or unclosed borders
- Repeated full compositions overlaid at opacity instead of true repeat cells
- Missing dominant-to-secondary-to-detail hierarchy
- Dense fills without intentional breathing room
- Primitive-only output when canonical motif silhouettes are available
- No visual proof of reference reconstruction

## Cultural integrity
Tradition-specific structural study is permitted only with accurate attribution and rights review. Do not reproduce sacred, restricted or community-protected motifs as generic merchandise.

## Promotion gate
No production promotion until branch is reconciled with main, CI passes, and a representative multi-scale SVG/raster visual review demonstrates coherence and production feasibility.
