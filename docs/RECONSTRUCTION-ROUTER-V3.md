# Reconstruction Router v3

Automatic one-method tracing is retired.

Each approved source glyph is routed by geometry:
- primitive reconstruction for regular geometric structures,
- centerline reconstruction for open/stroke forms,
- compound paths for closed/nested forms,
- hybrid reconstruction for mixed topology.

The raster crop remains locked visual authority. A method is a reconstruction strategy, never permission to redesign.

## Acceptance
1. Same source crop coordinate system.
2. Same component/hole topology.
3. Preserve intentional asymmetry.
4. Preserve intersections/endpoints/negative spaces.
5. Render-back overlay inspected at 1x and enlarged.
6. No smoothing or symmetry correction merely for aesthetics.
7. Geometry verification is per glyph, never batch inferred.
8. Only geometry-verified glyphs may be promoted to canonical-digital.

## Production derivative
Embroidery geometry is a child artifact of the canonical visual SVG. Manufacturing compensation may alter the derivative but never the canonical visual master.
