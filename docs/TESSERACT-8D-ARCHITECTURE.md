# Tesseract 2.0 — sparse 8D architecture

Tesseract remains one engine. “5D/6D/8D” describes progressively richer projections of one sparse state, not separate engines.

Dimensions:
1. Geometry — primitive/topological identity.
2. Semantics — concepts and weighted meanings.
3. Culture — provenance-bearing design intelligence.
4. Relations — compositional grammar.
5. Hierarchy — particle, glyph, compound, band, field, object.
6. Transformation — change through sequence/time.
7. Material — embodiment, technique, zone and manufacturing.
8. Provenance — evidence, confidence, access and transformation distance.

Pipeline:
intent -> evidence retrieval -> principle extraction -> semantic skeleton -> topology -> hierarchy -> cultural grammar -> transformation -> vector projection -> evaluation -> manufacturing validation.

Rules:
- Meaning and appearance remain separate.
- Historical claims require evidence and confidence.
- Indigenous traditions are stored at the most specific supported community/nation level.
- Sacred/restricted material is excluded from commercial synthesis.
- Cultural principles may guide structure without copying source motifs.
- ASCEND Core is distinct from historical corpora.
- The 108 Keys remain a separate ASCEND system and are not mandatory Heritage primitives.
- Legacy glyph geometry remains immutable.
- Anti-style memory penalizes known failure modes.
- Every generated feature can retain a provenance path.
- Complexity is measured as an 8-component vector, not a single aesthetic slider.
