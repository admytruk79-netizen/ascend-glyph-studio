# Projection Engine v0.1

Tesseract relational states are now projected into deterministic garment-zone placement manifests.

Supported projections: emblem, border, path, field and composition.

The projector changes only instance transforms (position, uniform scale, rotation and mirroring). It never edits source glyph paths. Zone geometry is currently development geometry for preview/solver integration, not a factory-approved pattern measurement.

Next production gate: replace development zone rectangles with pattern-piece polygons and seam/button exclusion geometry after the hero shirt pattern is validated.
