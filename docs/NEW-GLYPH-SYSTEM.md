# ASCEND New Glyph System

The redesigned system generates original SVG-native ASCEND glyphs. Historical material is used to study composition principles, never as geometry to trace. Legacy atlas fragments remain archived references and are not required inputs.

Lifecycle: research principle → abstract morphology → original vector construction → candidate → similarity/originality review → cultural review → manufacturing review → approved glyph/version.

IDs: `asc-new-###`. SVGs use a normalized 100×100 viewBox, deterministic geometry, explicit metadata and no raster dependency. Meanings assigned later are ASCEND meanings unless independently evidenced.
