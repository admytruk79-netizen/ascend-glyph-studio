# Increment 22: embroidery imagery replaces the sparse default

The development studio now opens on **Embroidered motifs**, with filled
red-and-black stars, nested diamond cells, branching floral cells and multiple
border scales. **Source imagery** displays actual retained Ukrainian ornament
plates 37 and 27 (1902, catalogue creator Nikolai Samokysh), plus the separately
attributed Norwegian placket annotation overlay. **ASCEND glyph studies** keeps
the earlier canonical template and machine-field checks accessible.

The five original screenshot files were no longer present at their attachment
paths during this increment. No fresh crop of those screenshots is claimed.
Their visible construction approaches guide the authored imagery, while the
real source-image gallery uses retained repository references. Source record
attribution and the earlier reference-use assessments remain unchanged; the
gallery is not fresh worldwide commercial image clearance.

The new imagery is deliberately separated from canonical ASCEND geometry and
manufacturing stitch IR. Its geometry namespace is `ornament-study`, its state
is REFERENCE, and the pixel-like grid is an illustration of counted embroidery,
not a calibrated stitch chart. It uses ordinary authored geometric motifs; it
does not reproduce a particular screenshot design, assign historical symbolism
or claim that experimental models generated the result. Canonical paths remain
unchanged, and neither imagery nor source photos are promoted to machine output.

Users can switch geometric/floral families, edit dimensions and repeat density,
change motif order, inspect the reference gallery and download the imagery SVG.
Stitch count is unavailable. The construction study remains outside checkout.
The change is committed on the development branch, not deployed to the live site.

Verified: engine typecheck/build, 51 engine test files with 184 passing tests,
web production build, and Playwright browser checks. The imagery view opens by
default; family selection changes it; all three actual source images load; SVG
download succeeds; no page errors or 390-pixel mobile horizontal overflow.
Geometric, floral, source-gallery and mobile screenshots were visually reviewed
and retained under `data/research/motif-benchmarks/embroidery-imagery-v1/`.

No new model training, live candidate activation, Neon write, digitization,
machine-file export, fabric calibration or production approval occurred.
Next is to replace the illustrative block-grid motifs with reviewed source
decomposition and validated construction rules before calling them engine-learned
or production-ready designs.
