# V4.1 Verification Gate

V4.1 corrected source segmentation by estimating the local parchment background per crop before skeletonization.

Before any canonical promotion, each Water/Air candidate must now satisfy:
- source mask contains glyph ink rather than parchment texture,
- centerline graph preserves visible branches/endpoints,
- render-back is compared at exact crop dimensions,
- topology and negative space match visually,
- no automatic batch promotion from a metric alone.

A failed candidate is routed to geometric/manual correction; it is not sent back to outline tracing.
