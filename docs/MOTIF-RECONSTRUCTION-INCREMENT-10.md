# Vytvory composition study and garment-region reference layouts

The Vytvory homepage, catalogue and product 278 were fetched and inspected, along with promotional photographs and the product's sweep image. The catalogue separates eight Ukrainian ethnoregions and the product cites historical shirt sample KYD58. Visual observations show dense ornament in selected garment regions, separate scales for narrower bands, quieter body areas, branching repeated fields and geometric border bands. The study record is `data/research/motif-annotations/vytvory-composition-study.json`; it records URLs, HTML hashes and bounded observations. These observations are not a claim of a botanical taxonomy or the exact identity of each piece in a flat sweep image.

Vytvory is used as a composition reference. Its templates, artwork and photos are not copied into engine fixtures, and its regional labels or KYD58 attribution are not transferred to the Neon source. The actual reconstruction geometry remains the Neon-selected, reference-reviewed 1902 Ukrainian plate 37.

A version-2 observed annotation retains the earlier v1 fixture unchanged and adds eight approximate visible petal-interior regions inside the large radial flower. It has 21 observed elements and 12 spatial nests. These are visible colour-region hypotheses, not expert petal boundaries or thread-fill plans. The original image hash and attribution remain unchanged.

`layoutReferenceMotifRegion` composes the existing MotifGraph into rectangular reference regions. It preserves original paths, ports, transforms, provenance, nests and protected negative spaces. It applies uniform scaling and authored translations, with optional alternating reflected rows. Reflected source repeats reverse their horizontal step. Grid repeats across rows are declared only between matching orientations; an alternating mirror is not falsely represented as a translation repeat.

Input source structure, ports, envelope and centreline clearances are checked before fitting, so the layout cannot hide invalid source geometry by recentering it. Existing minimum gap requirements remain unchanged and a scale that violates them fails closed. A cramped field, zero/nonfinite gaps, invalid grid, ID collision or invalid reconstructed structure is rejected. Output is always REFERENCE with productionApproved=false. Observed geometry is not relabelled as canonical ASCEND glyphs; no canonical production compiler or glyph geometry is changed.

`npm run benchmark:motif:regions` creates a 130 x 240 reference sleeve panel (2 x 5 motifs, alternating reflected rows), a 180 x 42 cuff reference (4 motifs), and a 180 x 25 collar reference (6 motifs). These dimensions are authored design references, not measured garment pieces. It emits engine-generated SVGs, graphs, a comparison gallery and a report under `artifacts/motif-reconstruction/garment-regions`. The command is included in the historical benchmark workflow through the existing script path filter.

The regions contain 210, 84 and 126 observed elements respectively. All annotated contacts, repeated placements and nests remain valid with no undeclared contour intersections or outside-envelope points. Minimum centreline gaps near declared junctions are extremely small; a zero-violation reference check does not establish thread-width clearance or manufacturing feasibility. Stroke widths, fills, actual fabric, hoop registration and stitch count remain unvalidated. No approval is inferred from the reference dimensions.

Tests cover deterministic output, unchanged source geometry/input data, preserved contacts/repeats/nests/negative space, bounded footprints and layout gaps, reflected protected regions and source repeats, retained petal interiors, cramped fields, invalid input geometry and scaling below the existing minimum gap. The benchmark report is retained as `docs/benchmarks/motif-region-layout-v1.json`.

Remaining: independently reviewed accurate contours; additional Neon floral families from plates 6 and 27; historically evidenced branch/repeat grammar; explicit canonical ASCEND mapping and final transformed-layout validation; physical garment placement and machine digitization. These layouts are authored reference grids, not inferred historical grammar, finished new ASCEND designs or machine stitch files. No training or production approval is claimed.

Local verification passed: `npm run verify:tesseract-worker` (153 engine tests, engine typecheck/build, production pilot, stitch-engine typecheck and 22 stitch tests), plus `npm run benchmark:motif:historical` (seven benchmark runners). The site study used actual fetched pages/images, and the engine preview was rendered and visually inspected. Remote CI and production deployment have not been verified for this increment.
