# Connected floral reconstruction from a Neon source

The existing engine now reconstructs a source-linked **draft** annotation from Neon-selected Commons object `commons-96737753`: Мотиви українського орнаменту, 1902, plate 37, with creator recorded as Nikolai Samokysh. The original acquired 1280 x 465 image, unchanged Neon record and hash-identified provenance are retained under `data/research/motif-references/commons-96737753/`. Neon itself was not modified.

The reference-use assessment relies on the preserved item-specific public-domain declaration and catalogue publication in 1902 (pre-1931 publication, public domain in the US). It does not claim a successful live Commons licence-page refresh or global commercial/manufacturing approval; the live requests returned HTTP 403. This documented assessment admits plate 37 for this reference reconstruction. Other shortlisted sources remain candidates requiring their own assessment. No query-group country label is used to establish the Ukrainian attribution; the catalogue title explicitly identifies the Ukrainian ornament series.

The committed observed annotation has 13 parts: one large radial flower, one hanging multi-lobed flower, two rounded flowers, four central/inset regions, a terminal bud and four connecting stems. There are eight explicitly annotated attachment contacts and four spatial nests. Stem ports lie on their paths; inset contours pass the existing conservative containment checks. Flower descriptions are visual hypotheses, not botanical or symbolic identifications. This is a partial region of the plate, not a decomposition of every flower or a recovered complete historical grammar.

The adapter and reconstruction reuse `graphFromObservedAnnotations`, typed MotifGraph, `reconstructMotif`, the existing structure/clearance measurements and engine SVG rendering. No engine or canonical ASCEND glyph geometry was replaced. The graph remains REFERENCE. Reference width 1280 normalizes coordinates one-to-one to source pixels; it is not a measured physical width in millimetres.

Run `npm run benchmark:neon:floral`. It verifies the retained image hash and dimensions, emits reference SVG, annotated source overlay, graph and benchmark report under `artifacts/motif-reconstruction/neon-plate37/`. The command is also included in `npm run benchmark:motif:historical` and the existing artifact-upload workflow.

No ports are off their paths, no reference contours intersect away from declared junctions, and no points exceed the reference envelope.
