# Tesseract Meta-Grammar

One semantic structure, many visual projections.

The canonical object is a meaning graph, not a drawing. Its current journey is:
root → axis → path → guardian → transformation → flowering → flight → ascent → crown → return.

A projection maps that same graph into a different spatial reading:
- linear band — borders and horizontal ornament
- vertical journey — spine and axial cover structures
- radial field — circles, recurrence and rotational compositions
- macro emblem — many components perceived as one larger sign
- layered field — nested/overlaid composition suitable for hidden secondary readings

Every projection carries the same semantic checksum. Thus two visibly different artifacts can be verified as descendants of one underlying structure.

This is an ASCEND compositional invention. It does not claim that the full graph or its meanings belong to any historical culture. Research traditions inform design intelligence separately.
